# The Signal · курс для Inkwell (v2 — Interactive Story Course)

Окремий застосунок у тому ж домені, що й Inkwell (як Life in LA): один файл `index.html`, без збірки.

## Встановлення

1. Покладіть папку `the-signal/` у репозиторій GitHub Pages під `odissey1505.github.io`.
2. Виконайте `signal_progress.sql` у Supabase SQL Editor (один раз).
3. Додайте в Inkwell посилання на курс.

Вхід уже налаштовано: блок **INKWELL AUTH** у кінці `index.html` створює клієнт Supabase (той самий проєкт і anon key, що в Inkwell), перевіряє сесію й викликає `startCourse(user)`. Сесія спільна для обох застосунків, бо вони в одному домені, тож повторно входити не треба.

## Режими входу

| Ситуація | Що відбувається | Прогрес |
| --- | --- | --- |
| Учень увійшов в Inkwell | `startCourse(user)` | таблиця `signal_progress` + браузер |
| Учень не увійшов | перенаправлення на `https://odissey1505.github.io/inkwell/` | — |
| Адреса з `?preview=1` | курс відкривається без входу | лише браузер |
| Бібліотека Supabase не завантажилась | курс відкривається в локальному режимі | лише браузер |

## Ролі: викладач і учень

Роль береться з таблиці Inkwell `profiles` (поле `role`) після входу. У `localStorage` вона не зберігається, тому учень не може ввімкнути режим викладача, змінивши дані в браузері.

| Можливість | Викладач (`role = 'teacher'`) | Учень, `?preview=1`, локальний режим |
| --- | --- | --- |
| Перемикач Teacher view / Student view | ✅ меню, кнопка 🧑‍🏫 в епізоді | — |
| Карта уроку 🧭 — перехід до будь-якого етапу чи екрана | ✅ | — |
| Вкладки частин уроку | усі відкриті | лише вже пройдені частини |
| Посилання на будь-який екран (`#/episode/c1a/50`) | відкривається | повертає до поточного екрана |
| Стрілки ← → між екранами | ✅ (коли курсор не в полі вводу) | — |
| Skip, нотатки, ключі, відкритий транскрипт | ✅ | — |
| «Start this episode again» — скинути свій епізод | ✅ (у карті уроку) | — |
| Вкладка **Students** — скинути епізод або весь курс учневі | ✅ | — |

`?teacher=1` в адресі одразу вмикає Teacher view, але лише для викладача. У Student view викладач бачить урок так, як учень (разом з обмеженнями), — зручно для перевірки.

## Що є в застосунку

- **Course** — «Continue your story», статистика, «Your journey» з 20 серіалами (●━●━○ — прогрес епізодів).
- **Сторінка серіалу** — обкладинка, три епізоди (Discover / Understand / Final Mission), команда персонажів.
- **Епізод** — один екран = одна дія (77 екранів у Епізоді 1), вкладки частин уроку, «N min left», сюжетні моменти на темному екрані.
- **My words** — слова, які учень додав кнопкою «+ My words»; статуси New → Learning → Familiar → Mastered; зірочки; тренування, яке першими повертає найслабші слова.
- **Progress** — досягнення, серія днів, налаштування (ім'я в локальному режимі, тема, Teacher view для викладачів, скидання прогресу).
- **Teacher view (🧑‍🏫)** — лише для викладачів: нотатки й ключі, карта уроку, вільні переходи. Учень не може перестрибнути далі, ніж дійшов (див. «Ролі»).

## Вкладка Students (лише для викладача)

Список учнів береться з таблиці `profiles` (усі з `role = 'student'`), прогрес — із `signal_progress`. Для кожного учня видно відсоток по епізодах, кількість зібраних слів і коли він востаннє займався.

- **Clear episode 1** — прибирає відповіді й проходження цього епізоду, слова в словнику лишаються.
- **Clear everything** — видаляє весь рядок прогресу учня в цьому курсі, разом зі словником.

Обидві кнопки вимагають підтвердження (натиснути двічі). Працюють лише з правилами доступу з `signal_progress.sql`: викладач може оновлювати й видаляти чужі рядки, учень — лише свій.

## Як додати наступний епізод

1. Додайте об'єкт у `window.SIGNAL_LESSONS` (формат — як у `c1a`).
2. У `SIGNAL_COURSE` поставте цьому уроку `content: true`.
3. Якщо епізоду потрібні нові типи екранів — додайте рендерер у об'єкт `X` і рядок у `screensOf()`.

## Аудіо

Діалоги озвучуються браузером (Web Speech API), кожна репліка — окреме «голосове». Набір голосів залежить від пристрою; для стабільного звуку заповніть `audioSrc` в етапі `listen`.

## Обкладинки серіалів

У `SIGNAL_COURSE` кожен цикл може мати поле `image` (URL або data URI) і `imageAlt`. Якщо картинку задано, вона замінює намальовану обкладинку на головній, на сторінці серіалу й на екрані завершення. Текст поверх неї не накладається: назва має бути на самій картинці.
Рекомендований формат — 16:9 (наприклад, 1675×939), WebP. Зараз обкладинка циклу 1 вбудована у файл; оригінал — `cover-c1.webp`.

Для широкого банера на сторінці серіалу є окреме поле `banner` (+ `bannerAlt`), формат приблизно 3,2:1 (зараз 2136×660, `banner-c1.webp`). На телефонах замість банера показується `image` 16:9, бо текст на широкому банері там стає задрібним.

## Фото персонажів

У `characters` уроку кожен персонаж має поле `img` (URL або data URI) і `face: { x, y }` — точку обличчя у відсотках.

- Велике фото показується на екрані «Judge me in 5 seconds» і в Instagram-профілі.
- Усі маленькі аватарки (шапка профілю, вибір персонажа, голосові повідомлення, команда, результати) — те саме фото, обрізане до обличчя за точкою `face`.
- Якщо `img` немає, використовується намальований SVG-портрет.

Формат: квадрат, від 800×800, WebP. Вбудовано фото всіх п'ятьох: `zoe-photo.webp`, `leo-photo.webp`, `dana-photo.webp`, `marko-photo.webp`, `nate-photo.webp`.
