# The Signal · курс для Inkwell

Інтерактивний сюжетний курс англійської для 8 класу (A2+ → B1). Окремий застосунок у домені `odissey1505.github.io`, вхід спільний з Inkwell.

## Структура

```
the-signal/
├── index.html                  ← головний файл: лише оболонка й підключення скриптів
├── css/
│   ├── signal.css              ← увесь дизайн (кольори, шрифти, екрани)
│   └── fashion.css             ← тема «Style & Music» для Unit 2 (екрани з fashion.js)
├── js/
│   ├── config.js               ← налаштування: адреса Inkwell, таблиця прогресу, VERSION
│   ├── course.js               ← карта курсу: 5 сезонів, 20 серіалів, 60 епізодів
│   ├── core.js                 ← ядро: прогрес, словник, головна, My words, Progress, Students
│   ├── player.js               ← програвач епізодів: екрани, карта уроку, роутер
│   ├── art/
│   │   └── wardrobe.js         ← малюнки одягу (flat lay, SVG): образи, речі, старе фото 1998
│   ├── screens/
│   │   ├── story.js            ← сюжетні екрани: груповий чат, голосове, дошка доказів… (епізоди B)
│   │   ├── review.js           ← екрани повторення й фінальних місій: чат «Next message», слова в пропуски, дошка доказів… (епізоди C)
│   │   └── fashion.js          ← екрани Unit 2: пари протилежностей, гра, Outfit Detective, таймлайн, машина часу, конструктор образу…
│   └── auth.js                 ← вхід через Inkwell (Supabase), запускає курс
├── lessons/
│   ├── c1a-first-impressions.js   ← зміст епізоду: персонажі, слова, етапи, аудіо, ключі
│   ├── c1b-behind-the-profile.js  ← Present Simple vs Continuous, розслідування
│   ├── c1c-behind-the-message.js  ← повторення циклу 1 + фінал історії
│   └── c2a-whats-your-style.js    ← Урок 4: одяг і стиль, музика й мода, місія «образ Марка»
├── assets/
│   ├── covers/                 ← обкладинки серіалів
│   │   ├── c1-cover.webp  c2-cover.webp    (16:9 — головна, екран завершення)
│   │   └── c1-banner.webp c2-banner.webp   (≈3,2:1 — сторінка серіалу)
│   └── characters/             ← фото персонажів
│       ├── zoe.webp  leo.webp  dana.webp  marko.webp  nate.webp
│       └── leo-today.webp  dana-today.webp  marko-today.webp
├── sql/
│   └── signal_progress.sql     ← таблиця прогресу й правила доступу (виконати в Supabase)
└── tools/
    └── check-course.js         ← перевірка перед публікацією
```

Що зазвичай редагується:

| Завдання | Файл |
| --- | --- |
| Додати або змінити епізод | `lessons/…js` + рядок у `js/course.js` |
| Назви, слогани, обкладинки серіалів | `js/course.js` + картинки в `assets/covers/` |
| Фото персонажа | `assets/characters/…webp` (шлях — у файлі уроку, поле `img`) |
| Кольори, шрифти, вигляд | `css/signal.css` (Unit 2 — `css/fashion.css`) |
| Одяг на малюнках Уроку 4 | об'єкт `LOOK` на початку `lessons/c2a-whats-your-style.js` |
| Адреса Inkwell, назва таблиці | `js/config.js`, `js/auth.js` |

`core.js` і `player.js` — рушій; для нових уроків їх змінювати не потрібно, якщо урок використовує вже наявні типи екранів.

## Публікація

1. Покладіть папку `the-signal/` у репозиторій GitHub Pages під `odissey1505.github.io`.
2. Один раз виконайте `sql/signal_progress.sql` у Supabase SQL Editor.
3. Додайте в Inkwell посилання на курс.
4. Після кожного оновлення змініть версію в двох місцях: `VERSION` у `js/config.js` і `?v=` в `index.html`. Інакше браузери учнів можуть ще якийсь час показувати старі файли з кешу.

Локально курс відкривається через будь-який простий сервер, наприклад `python3 -m http.server` у батьківській папці, далі `http://localhost:8000/the-signal/`.

## Як додати новий епізод

1. Скопіюйте наявний урок як основу, наприклад `lessons/c2a-whats-your-style.js` → `lessons/c2b-best-night-ever.js`.
2. Змініть ключ: `window.SIGNAL_LESSONS.c2b = { id: "c2b", … }`.
3. У `js/course.js` знайдіть рядок епізоду й допишіть:
   `content: true, file: "lessons/c2b-best-night-ever.js"`
4. Запустіть перевірку (потрібен Node.js):
   ```
   cd the-signal
   node tools/check-course.js
   ```
   Скрипт перевіряє, що файл існує й реєструє урок, що всі типи екранів відомі, що таймінг ≈60 хв, що всі картинки на місці.

Уроки підвантажуються автоматично за списком у `course.js`. Якщо файл уроку не знайдеться, курс усе одно відкриється, а епізод покажеться як «Soon».

Якщо новому епізоду потрібні нові типи екранів, їх додають у бібліотеку в `js/screens/` через `SignalPlayer.define("тип", render, { label })`, а новий файл бібліотеки підключають в `index.html` після `js/player.js`. Урок перелічує свої екрани у функції `screens(add, st)`.

Екрани з `js/screens/review.js` і `js/screens/fashion.js` майже ніколи не блокують кнопку Continue: завдання можна пройти усно. Кнопки Check / Try again / Reset, переклад і приклади — усередині екрана. Чекають лише сюжетні чати (поки не з'являться всі повідомлення й не буде голосу в опитуванні) — у Teacher view кнопка активна завжди.

## Урок 4 (c2a) · What's Your Style?

Unit 2 · In fashion, урок один на один, ≈59 хв. Vocabulary + Reading + Speaking; Past Simple тут не вивчається (текст про епохи — у теперішньому часі). 12 слів = 6 пар протилежностей, вони додаються в My words.

Малюнки одягу генеруються кодом (`js/art/wardrobe.js`), тому урок працює без зовнішніх картинок. Два місця можна пізніше замінити реалістичними зображеннями — достатньо покласти файл в `assets/` і вписати шлях у файл уроку:

| Що | Поле в `lessons/c2a-whats-your-style.js` | Формат |
| --- | --- | --- |
| Обкладинка уроку (підлітки в різних стилях) | stage `opening` → `img` | 16:9 |
| Старе фото тата з концерту 1998 | stage `ending` → `photo.img` | вертикальне ≈300 × 340 |

Доки поле `null`, показується колаж із фото персонажів і намальоване «плівкове» фото.

## Картинки

| Що | Де лежить | Формат | Де вказано шлях |
| --- | --- | --- | --- |
| Обкладинка серіалу | `assets/covers/cN-cover.webp` | 16:9, від 1600 px, назва на картинці | `image` у `course.js` |
| Банер серіалу | `assets/covers/cN-banner.webp` | ≈3,2:1, від 2000 px | `banner` у `course.js` |
| Фото персонажа | `assets/characters/<ім'я>.webp` | квадрат, від 800 px | `img` у файлі уроку |

Для фото персонажа також задається `face: { x, y }` — точка обличчя у відсотках; за нею кадруються маленькі аватарки. Серіали без картинок показують кольорову обкладинку з емодзі.

## Ролі: викладач і учень

Роль береться з таблиці Inkwell `profiles` (поле `role`) після входу й не зберігається в браузері.

| Можливість | Викладач | Учень / `?preview=1` |
| --- | --- | --- |
| Teacher view / Student view (🧑‍🏫) | ✅ | — |
| Карта уроку 🧭, стрілки ← →, посилання на будь-який екран | ✅ | лише пройдені частини |
| Нотатки, ключі, Skip, відкритий транскрипт | ✅ | — |
| «Start this episode again» — скинути свій епізод | ✅ | — |
| Вкладка Students — скинути епізод або весь курс учневі | ✅ | — |

`?teacher=1` в адресі вмикає Teacher view одразу, але лише для викладача.

## Режими входу

| Ситуація | Що відбувається | Прогрес |
| --- | --- | --- |
| Учень увійшов в Inkwell | курс відкривається | таблиця `signal_progress` + браузер |
| Не увійшов | перенаправлення на Inkwell | — |
| `?preview=1` | курс без входу | лише браузер |
| Бібліотека Supabase не завантажилась | локальний режим | лише браузер |
